Privacy Policy

Effective Date: June 4, 2026

TL;DR — LimitLens is local-first. It does not collect analytics or send data to LimitLens servers. Some optional providers can make direct requests from your machine to the provider's own API when you explicitly configure credentials for that provider.

1. What LimitLens Does

LimitLens is an open-source command-line utility and desktop companion that reads locally stored configuration files, SQLite databases, and session data from AI coding tools installed on your computer. It aggregates quota usage information and displays it in your terminal, macOS menu bar, or iTerm2 status bar.

2. Data We Collect

None by LimitLens. LimitLens does not collect or upload personal data to any LimitLens-operated service. Specifically:

  • No analytics or telemetry is sent by the CLI
  • No crash reports are uploaded
  • No API keys, tokens, cookies, or usage statistics are sent to LimitLens
  • Optional web-backed providers only contact their own configured provider endpoints from your machine
  • No cookies or tracking pixels are used on this website

3. Data LimitLens Reads Locally

To provide quota monitoring, LimitLens reads the following data from your local filesystem. This data is stored locally and is not sent to LimitLens:

  • Configuration files — JSON config files from tools like Cursor, Codex, Amp, and others to determine subscription tiers and usage limits
  • Local SQLite databases — Rate-limit and session databases maintained by AI coding tools on your machine
  • Session tokens (read-only) — Used solely to calculate remaining quota headroom or authenticate direct provider API checks when that provider is enabled; never stored by LimitLens
  • File paths & email addresses — Detected in configs but actively redacted from all CLI output to protect your privacy

4. Data Storage

LimitLens stores a minimal local cache in ~/.limitlens/ on your machine. This cache contains only:

  • Aggregated quota percentages (no raw tokens or keys)
  • Timestamp of last scan
  • User preferences (display format, enabled providers)

You can delete this directory at any time to completely remove all LimitLens data from your system.

5. Third-Party Services

LimitLens does not use telemetry, analytics, or LimitLens-hosted backend services. Most providers are read from local files/databases. Some optional providers, such as Cursor, Pioneer, AgentRouter, and Command Code, can make direct HTTPS requests from your machine to that provider's API when credentials are configured. Those requests go only to the provider endpoint needed to fetch quota or usage data.

This website is hosted on Vercel, which may collect standard web server logs (IP address, user agent, referrer) as part of normal HTTP serving. Please review Vercel's Privacy Policy for details on their data practices.

6. Open Source Transparency

LimitLens is fully open-source under the MIT License. You can audit every line of code to verify these privacy claims. We believe transparency is the strongest privacy guarantee.

7. Children's Privacy

LimitLens does not collect any data from anyone, including children under the age of 13. Since no data is collected, no special provisions are necessary under COPPA or similar regulations.

8. Changes to This Policy

If we update this privacy policy, changes will be reflected on this page with an updated effective date. Since LimitLens collects no data, meaningful changes to this policy are unlikely.

9. Contact

If you have questions about this privacy policy or LimitLens's data practices, please open an issue on GitHub or reach out to the maintainer via the repository.
