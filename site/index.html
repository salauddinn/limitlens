Get Started in Seconds

Install locally via your package manager or directly run the onboarding installer script.

curl -fsSL https://raw.githubusercontent.com/salauddinn/limitlens/main/install.sh | bash

Automatically registers the macOS menubar app and configures path settings.

pipx install "git+https://github.com/salauddinn/limitlens.git[mac]"

Installs core CLI plus rumps module required to power the macOS menubar app.

pipx install "git+https://github.com/salauddinn/limitlens.git"

Installs the core CLI utility. Fully compatible with Linux and Windows systems.
